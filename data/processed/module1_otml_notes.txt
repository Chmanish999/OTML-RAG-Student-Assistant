What do we mean by data in machine learning?
Answer:
In ML, data is the foundation of learning. It consists of examples or observations from which the model learns patterns.
===== Slide 16 =====
Numerical Data:
Numerical data consists of numbers and can be further classified into two subtypes:
Continuous Data: Continuous data can take any real value within a specific range. Examples include height, weight, temperature, and time.
Discrete Data: Discrete data can only take specific, distinct values. Examples include counts of objects, scores on a test, and the number of items sold.
Categorical Data:
Categorical data represents categories or labels and can be further classified into two subtypes:
Ordinal Data: Ordinal data has a natural ordering or hierarchy between categories. Examples include rankings (e.g., "low," "medium," "high") and survey responses (e.g., "strongly disagree," "disagree," "neutral," "agree," "strongly agree").
Nominal Data: Nominal data consists of categories with no inherent order or hierarchy. Examples include colors, gender, nationality, and types of animals.
===== Slide 17 =====
Tools in Machine Learning,
Text Data:
Text data consists of sequences of characters or words and is commonly encountered in natural language processing (NLP) tasks. Examples include text documents, emails, tweets, and customer reviews.
Image Data:
Image data consists of visual representations of objects, scenes, or patterns. Each image is typically composed of pixels, with each pixel representing a color value. Image data is commonly used in computer vision tasks such as object detection, image classification, and image segmentation.
Audio Data:
Audio data consists of sound waveforms recorded over time. Each audio sample represents the intensity of sound at a specific time point. Audio data is used in tasks such as speech recognition, speaker identification, and emotion detection.
===== Slide 18 =====
Tools in Machine Learning,
Time Series Data:
Time series data consists of observations collected at regular intervals over time. Each data point is associated with a timestamp or time index. Time series data is commonly encountered in forecasting tasks, stock market analysis, weather prediction, and sensor data monitoring.
Understanding the types of data present in a dataset is crucial for selecting appropriate data preprocessing techniques, feature engineering methods, and machine learning algorithms.

===== Slide 20 =====
Machine Learning Categories
Supervised Learning: Uses labeled data to train models for predictions or classifications.
Unsupervised Learning: Identifies patterns and relationships in unlabeled data.
Reinforcement Learning: Trains agents by rewarding desired actions and penalizing undesired ones
Supervised Learning
A. Classification Algorithms:
Logistic Regression: Predicts categorical outcomes using a logistic function.
Naive Bayes Classifier: Uses Bayes’ theorem for probabilistic classification.
K-Nearest Neighbor (KNN): Classifies data points based on their proximity to neighbours.
Support Vector Machine (SVM): Finds the best hyperplane to classify data.
Example: Email spam detection, speech recognition.
B. Regression Algorithms:
Linear Regression: Models the relationship between variables by fitting a straight line.
Ridge Regression: Adds regularization to linear regression to prevent overfitting.
Ordinary Least Squares (OLS): Minimizes the sum of squared differences between observed and predicted values.
Stepwise Regression: Sequentially adds or removes predictors to improve the model.
Example: Stock market prediction, rainfall prediction.
===== Slide 21 =====
2. Unsupervised Learning
A. Clustering Algorithms:
K-Means: Groups data into clusters based on similarity and minimizes intra-cluster variance.
K-Median: Similar to K-Means but minimizes median distance instead of variance.
Hierarchical Clustering: Creates a hierarchy of clusters using dendrograms.
Expectation-Maximization: Alternates between expectation and maximization steps to cluster data probabilistically.
Example: Identifying fake news, document analysis.
B. Association Analysis:
APRIORI: Finds frequent itemsets in a dataset and derives association rules.
Eclat: A faster variation of APRIORI using depth-first search.
FP-Growth: Efficiently discovers frequent itemsets using a tree-based approach.
Example: Market basket analysis
C. Dimensionality Reduction:
Feature Extraction:
Principal Component Analysis (PCA): Reduces dimensions by transforming features into principal components.
Feature Selection:
Wrapper: Selects features by evaluating subsets.
Filter: Selects features based on statistical properties.
Embedded Method: Performs feature selection during model training.
Example: Analysis of written texts and DNA microarray data.
===== Slide 22 =====
3. Reinforcement Learning
A. Model-Free Methods:
Q-Learning: Uses Q-values to learn optimal actions in an environment.
Hybrid: Combines model-free methods with other strategies.
Policy Optimization: Optimizes a policy directly for better decision-making.
B. Model-Based Methods:
Learn the Model: Creates an explicit model of the environment for decision-making.
Given the Model: Uses a pre-existing model to optimize actions.
Example: Multi-agent systems, motion planning, navigation

===== Slide 29 =====
Why Optimization Techniques Are Essential in Machine Learning:
Machine learning models, despite being more flexible and data-driven than traditional programming, fundamentally rely on optimization………
The core task in most machine learning algorithms is to find the best parameters that minimize some measure of error or maximize performance.
This process is an optimization problem.
===== Slide 30 =====
Machine Learning as an Optimization Process
Every supervised machine learning algorithm can be formulated as solving an optimization problem.
For example:
===== Slide 31 =====
Linear regression aims to minimize the mean squared error.
Logistic regression aims to minimize cross-entropy loss.
Support vector machines aim to  maximize the margin between classes.
Neural networks aim to minimize a complex loss function using gradient-based methods.
Thus, the core of “learning” in machine learning is
an optimization process.
===== Slide 32 =====
Optimization Enables Generalization
Optimization is not just about minimizing the training loss. With techniques like regularization (Ridge, LASSO), we use optimization to find models that generalize well to unseen data.
This helps in managing the bias–variance trade-off and reduces overfitting

Neural networks: Trained via backpropagation using gradient descent.
SVM: Solved using quadratic programming.
K-means clustering: Minimizes intra-cluster variance.
PCA: Involves maximizing variance (eigenvalue optimization).
Reinforcement learning: Optimizes a reward function over time.

Conclusion on ERM :
ERM minimizes training error only.

What is Parameter Estimation?
In machine learning, we build models to predict or explain things. These models have certain parameters — like the slope and intercept in a straight-line equation — that need to be "learned" from data.
Parameter estimation is the process of figuring out the best values for these parameters, using the data we have.
machine learning and OTML, we usually work with samples, and our goal is to estimate unknown parameters (like μ )using estimators (like xˉ).

Point estimation is the process of using sample data to compute a single best-guess value (called an estimator) for an unknown population parameter such as:
Mean
Proportion

In machine learning, point estimation is used to estimate model parameters that are later optimized during training.

===== Slide 100 =====
1.1 Maximum Likelihood Estimation (MLE)
Definition: Maximum Likelihood Estimation (MLE) is a method of estimating the parameters of a statistical model by choosing values that maximize the likelihood of the observed data.
MLE answers the question:
“Given the data I observed, which parameter value makes this data most likely to occur?”
Usage in OTML:
Transforms a probabilistic model into an optimization problem.
Foundation for learning in logistic regression, naive Bayes, Gaussian models.
Leads to loss functions (e.g., cross-entropy) used in deep learning.

===== Slide 129 =====
A confidence interval
provides a range of values which is likely to contain the true value of a population parameter
(such as the mean μ) with a given level of confidence.
===== Slide 130 =====
For example, a 95% confidence interval means that if we took 100 different samples and calculated an interval for each, about 95 out of those 100 intervals would contain the true population mean.
This is a frequentist concept, meaning the confidence level refers to the frequency of coverage across repeated samples.
===== Slide 131 =====
This formula assumes:
The underlying distribution is normal or the sample size is large (by Central Limit Theorem).
The population standard deviation σ is known
===== Slide 132 =====
A confidence interval does not say that the parameter has a certain probability of lying in the interval (that’s Bayesian), but rather, the procedure used to calculate it will produce correct intervals in a certain percentage of repeated samples.
In machine learning, such intervals help you measure and communicate the uncertainty of your model’s estimates and predictions.

A credible interval is a Bayesian concept.
It represents an interval within which the parameter θ lies with a given probability (e.g., 95%) based on the observed data.
“There is a 95% probability that the true parameter θ lies within this interval — given the data DDD.”
This is different from classical confidence intervals (frequentist), where the parameter is fixed and the interval is random.

What are Directed Graphical Models (DGMs)?
“A Directed Graphical Model (also called a Bayesian Network) is a probabilistic model that uses a directed acyclic graph (DAG) to represent:
Random variables as nodes
Conditional dependencies as directed edges
Each node represents a variable, and an arrow from node A to node B means that B is conditionally dependent on A.”

In machine learning and optimization, constrained optimization refers to minimizing (or maximizing) an objective function
subject to certain restrictions (constraints).
General form:
Minimize:𝑓(𝑥)
Subject to:
𝑔𝑖(𝑥)=0(equality constraints)
and/or
ℎ𝑗(𝑥)≤0(inequality constraints)
===== Slide 184 =====
2. Why Constraints in Machine Learning?
Constraints arise in ML when:
Model parameters must satisfy certain conditions (e.g., probabilities must sum to 1)
Regularization introduces constraint-like behavior
Optimization is subject to resource limits (e.g., budget, time, fairness)
when constraints are present, plain gradient descent fails to give a valid solution. That’s why we need Lagrange multipliers or similar constrained optimization techniques.

1. What is Convex Optimization?
Convex Optimization is a subfield of optimization where:
The objective function is convex
The feasible region (set of solutions allowed by constraints) is also convex
This structure ensures that any local minimum is also a global minimum, which is very desirable in machine learning.
