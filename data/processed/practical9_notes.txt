## 3. Theory Background

A Directed Graphical Model is a graph-based representation of relationships among variables.

It contains:

| Component | Meaning |
|---|---|
| Node | Represents a variable |
| Directed edge | Represents direction of dependency |
| Parent variable | Variable that influences another variable |
| Child variable | Variable influenced by a parent variable |

A directed edge is written as:

--- Code Cell 3 ---
import networkx as nx
import matplotlib.pyplot as plt

--- Code Cell 4 ---
G = nx.DiGraph()

G.add_node("Age")
G.add_node("Gender")
G.add_node("Music Genre")

G.add_edge("Age", "Music Genre")
G.add_edge("Gender", "Music Genre")

--- Code Cell 5 ---
plt.figure(figsize=(7, 5))

pos = nx.spring_layout(G, seed=42)

nx.draw(
    G,
    pos,
    with_labels=True,
    node_size=3000,
    font_size=12,
    arrows=True
)

plt.title("Directed Graphical Model for Music Recommendation")
plt.show()

--- Code Cell 6 ---
print("Dependencies in the Directed Graphical Model:")

for edge in G.edges():
    print(edge[0], "influences", edge[1])
