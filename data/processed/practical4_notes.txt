## 3. Theory Background

In machine learning, a model learns from data by estimating some internal values or rules. These internal values are called **parameters**.

Parameters help a model convert input data into output predictions.

Examples of parameters in different machine learning models are:

| Model | Parameters |
|---|---|
| Linear Regression | Weights and bias |
| Decision Tree | Split rules |
| Neural Network | Weights and biases |
| Support Vector Machine | Hyperplane coefficients |

**Parameter estimation** means finding the best parameter values using training data.

In simple terms:

```text
Parameter Estimation = Finding the best internal model values from data
```

The goal of parameter estimation is:

```text
Best prediction with minimum error
```

In this practical, a Decision Tree Classifier is used. In a decision tree, the learned parameters are not simple numerical weights like linear regression. Instead, the model estimates decision rules such as:

```text
If age is in a certain range and gender has a certain value, then predict a particular music genre.
```

Thus, the model estimates rules from data and uses those rules for prediction.

---

## 4. Link with Optimization in Machine Learning

Parameter estimation is directly connected with optimization.

In machine learning, the model tries to find the best parameters that reduce prediction error. This process can be understood as an optimization problem.

The general idea is:

```text
Find parameters that minimize error or loss
```

For example:

- Linear Regression estimates weights by minimizing Mean Squared Error.
- Logistic Regression estimates parameters by minimizing classification loss.
- Neural Networks estimate weights using gradient descent.
- Decision Trees estimate split rules by improving class separation.

In this practical, the Decision Tree model learns decision rules from the dataset. These rules are selected in such a way that the model can classify the training examples as accurately as possible.

Therefore, parameter estimation is one of the core steps in model fitting and optimization-based learning.

## What are Parameters?

Parameters are internal values or rules learned by a machine learning model from data. These values help the model make predictions.

Parameter estimation means finding the best parameter values or decision rules using training data. The goal is to achieve better prediction with minimum error.

| Model | Parameters |
|---|---|

--- Code Cell 4 ---
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.tree import DecisionTreeClassifier, plot_tree

--- Code Cell 5 ---
df = pd.read_csv("music1.csv")
df.head()

--- Code Cell 6 ---
X = df[["age", "gender"]]
y = df["gener"]

model = DecisionTreeClassifier(random_state=42)
model.fit(X, y)
model

--- Code Cell 7 ---
plt.figure(figsize=(12, 8))
plot_tree(
    model,
    feature_names=["age", "gender"],
    class_names=model.classes_,
    filled=True
)
plt.show()

--- Code Cell 8 ---
sample = pd.DataFrame([[22, 1]], columns=["age", "gender"])
prediction = model.predict(sample)
print("Predicted Genre:", prediction[0])
