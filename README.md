\# OTML RAG Student Learning Assistant



. 1. Project Title



\-OTML RAG Student Learning Assistant-



This project is a Retrieval-Augmented Generation (RAG)-based student assistant developed for the subject:



\-A8751 – Optimization Techniques in Machine Learning (OTML)-



The assistant answers student questions based only on:



1\. OTML Module 1 PPT material  

2\. OTML Practical 1–9 GitHub repositories  

3\. Local processed RAG knowledge base  



\---



. 2. Project Objective



The objective of this project is to build a subject-specific AI assistant that helps students understand OTML Module 1 concepts in a simple and structured manner.



The assistant does not answer from general internet knowledge. It retrieves relevant OTML content from the prepared local knowledge base and then generates a student-friendly response using Gemini.
